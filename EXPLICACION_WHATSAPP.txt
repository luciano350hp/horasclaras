HorasClaras — Explicación para pasarle a alguien

Es un sistema web para gestionar horas y tarifas de profesionales freelance (profesoras de idiomas y traductoras). Permite registrar horas de trabajo, calcular montos a facturar (con descuentos por repetición en traducciones) y generar resúmenes.

Stack:
- Backend: Python + FastAPI + SQLAlchemy + SQLite + Pydantic
- Arquitectura: 5 capas (Controllers, Services, Repositories, Entities, DTOs)
- Frontend: React + Vite (todavía no lo hice)
- IA/Agentes: OpenCode + AGENTS.md + Skills + Agentes (backend, frontend, revisor) + OpenSpec (SDD: especificar antes de codear)
- MCP: 4 servidores (filesystem, engram, memory, context7 - este último externo)
- Tests: 41 tests que pasan

Estado del TP (UNLa):
- Casos de uso: 2 hechos (CU-02 Clientes, CU-03 Horas), 8 pendientes. Necesito llegar a >=7 para aprobar el punto de funcionalidad.
- Puntos asegurados: ~5.6/10 (me faltan ~1.4). Aprobás con 7/10.
- Entrega final: 27/10/2026. Demo esta semana (no obligatoria).

Lo clave del proyecto: no programé todo yo solo, le enseñé a la IA cómo hacerlo (reglas, recetas/skills, agentes con roles, y especificaciones antes de escribir código). Eso es lo que quiero mostrar en la demo.
